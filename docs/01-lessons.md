# Өмнөх төслийн сургамжууд

Хуучин nexus (2026-08-19, устгагдсан) дээр гарсан алдаанууд ба энэ төсөлд
эхнээсээ мөрдөх дүрмүүд. 2026-08-20-нд хэрэглэгчтэй тохирсон.

## DB / RLS

1. **Нэвтрэлт/танилттай холбоотой аливаа хайлт RLS-ийн өмнө байрлана.**
   Session token, имэйлээр хэрэглэгч хайх, audit prev_hash, API түлхүүр,
   OIDC client lookup — эдгээр нь tenant тодорхойлогдохоос ӨМНӨ уншигддаг
   тул энгийн SELECT нь RLS-д чимээгүй хаагдаж "олдсонгүй" болдог (4 удаа
   давтагдсан). Эхнээсээ **SECURITY DEFINER функцийн давхарга** — зөвхөн
   шаардлагатай баганыг буцаана, нөхөж засахгүй.
2. **Audit hash гинжийг DB дотор тооцно.** Postgres jsonb-ийг хэвшүүлдэг
   тул Go талд тооцсон hash хэзээ ч тохирохгүй. Цагийг advisory lock
   доторх `clock_timestamp()`-ээр авна.
3. **Эрх өргөмжлөлийг GUC-ээр шалгахгүй** — зөвхөн DB role
   (`pg_has_role`). Апп хэзээ ч superuser-ээр холбогдохгүй (superuser
   FORCE RLS-ийг ч тойрдог).

## Build / Deploy

4. **Push бүрийн өмнө `GOOS=linux GOARCH=amd64 go build ./...`** — argon2
   нь x/sys/cpu-г зөвхөн linux/amd64 дээр ачаалдаг, macOS build цэвэр
   гарсан ч linux дээр унадаг. Makefile-ийн push урсгалд суулгасан.
5. **systemd дээр pnpm/corepack дуудахгүй** — ProtectHome-той мөргөлддөг.
   `node_modules/.bin/next start` шууд.
6. **deploy.sh эхний өдрөөс** — гараар хийдэг алхам бүр хожим гацаа болдог
   (goose PATH, migration owner гэх мэт).

## Код

7. Handlers эхнээсээ тусдаа package (import cycle-ээс сэргийлнэ).
8. Parse/encode бүх кодод unit тест заавал (API түлхүүрийн `_` split
   алдааг зөвхөн тест барьсан). base64url утгыг `_`-ээр Split хийхгүй —
   `SplitN`.
9. SQL функцийн параметрт үргэлж explicit cast (integer literal ≠
   smallint → 42883; нэг параметр хоёр контекстэд → 42P08).
10. JSON `null` ≠ SQL NULL — jsonb массив шүүхдээ
    `jsonb_typeof(...) = 'array'` хамгаалалт.
11. DB-ийн бүх string баганад урттай хязгаар (varchar(n) / CHECK) —
    задгай text хориотой.

## Процесс

12. **Дизайн зохиохгүй, жишгээ дагана.** open-gerege-nexus-ийн UI chrome
    шууд жишиг (өмнө нь 3-4 удаа дахин хийлгэсэн). Landing/portal-ийн
    chrome-ийг эхэнд нь screenshot-оор баталгаажуулна.
13. **Үе шаттай** — цөм ажиллаж баталгаажаагүй байхад дараагийн давхаргыг
    эхлэхгүй. Бүгдийг зэрэг барьсан нь өмнөх төслийн хамгийн том алдаа.
14. CSS grid дотор өргөн контенттэй элементэд `min-width: 0`.
